## 🚀 Featured Projects

### 🎙️ [Voice-Operated Calculator](https://github.com/anub1004/Voice-operated-Calculator)
`JavaScript` · `Web Speech API` · `HTML` · `CSS`

A browser-based calculator you control with your voice. No keyboard needed.

- 🔊 Real-time speech recognition using the Web Speech API
- 🧠 Parses spoken numbers and operators into calculations
- 🛡️ Handles invalid commands and continuous input
- 📱 Responsive, accessible UI

### 🎨 Animated Portfolio Website
`React` · `React Router` · `CSS (HSL theming)` · `EmailJS` · `Local Storage`

A dynamic personal portfolio with a working contact form. Won **top position** at the departmental project showcase.

- ⚛️ Single-page navigation with React Router
- 🎨 HSL-based color themes, with the user's choice saved in Local Storage
- 📧 Contact form via EmailJS that delivers straight to my inbox
- 🧱 Modular, reusable components across all screen sizes

### 💰 [Financial Application](https://github.com/anub1004/YOUR-FINANCIAL-REPO)
`React` · `Node.js` · `Express` · `MongoDB`

A full stack finance app for managing money in one place: tracking income and expenses and seeing where it all goes.

- 📈 Add, edit, and categorize income and expense transactions
- 📊 Dashboard with summaries and spending insights
- 🔐 Secure user accounts so each person sees only their own data
- 🗄️ REST API backed by MongoDB for persistent storage

### 🧾 [No Dues](https://github.com/anub1004/YOUR-NO-DUES-REPO)
`React` · `Node.js` · `Express` · `MongoDB`

A digital no-dues clearance system that replaces the paper-based process of collecting approvals from different departments.

- 📝 Students submit a clearance request online
- ✅ Each department reviews and approves or rejects, with remarks
- 🔔 Live status tracking, so students always know what's pending
- 👥 Separate views for students and approving authorities
